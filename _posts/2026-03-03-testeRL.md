# Introdução

Neste post iremos realizar testes das nossas  implementações dos otimizadores de Regressão Linear: Batch Gradient Descent, Stochastic Gradient Descent e do Mini Batch Gradient Descent em comparação com a implementação de Regressão Linear da biblioteca Scikit-Learn. O Scikit-Learn foi escolhido por ser um padrão da indústria e por ter uma solução fechada do LinearRegression, que nos irá servir como uma referência de qualidade.



# Descrição do Dataset

O dataset escolhido para esses testes foi o [Auto MPG](https://archive.ics.uci.edu/dataset/9/auto+mpg), já que é um conjunto clássico para regressão linear, apresenta um tamanho pequeno(398 amostras) e possui features em escalas bem diferentes, interessante para mostrar a necessidade da normalização. O dataset possui 8 features: displacement, cylinders, horsepower, weight, acceleration, model_year, origin, car_name e como target a coluna mpg.
No pré-processamento removemos a coluna car_name, pois era categórica, e  duas linhas que possuíam a variável horsepower com valor faltante.

## Código Python


```python

import pandas as pd
import numpy as np
from sklearn.linear_model import LinearRegression, SGDRegressor
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics import mean_squared_error

df = pd.read_csv("/home/joao/Documents/BibMatrix/AlgBIB/mpg.csv")
df = df.dropna()  # remover as 2 linhas com NaN

X = df.drop(columns=["mpg"]).values
y = df["mpg"].values

scaler = MinMaxScaler()
X_norm = scaler.fit_transform(X)

# 1. Solução exata
lr = LinearRegression()
lr.fit(X_norm, y)
pred_lr = lr.predict(X_norm)
mse_lr = mean_squared_error(y, pred_lr)
j_lr = mse_lr / 2

print("=" * 50)
print("SOLUÇÃO EXATA (LinearRegression)")
print("=" * 50)
print(f"Funcao Custo J (SSE/2m): {j_lr:.5f}")
print(f"MSE: {mse_lr:.5f}")

# 2. SGD 500 épocas
sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.001,
    max_iter=500,
    shuffle=True,
    random_state=42,
    penalty=None
)
sgd.fit(X_norm, y)
pred_sgd = sgd.predict(X_norm)
mse_sgd = mean_squared_error(y, pred_sgd)
j_sgd = mse_sgd / 2

print()
print("=" * 50)
print("SGDRegressor (500 epocas, taxa=0.001)")
print("=" * 50)
print(f"Funcao Custo J (SSE/2m): {j_sgd:.5f}")
print(f"MSE: {mse_sgd:.5f}")

# 3. SGD 5000 épocas
sgd2 = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.001,
    max_iter=5000,
    shuffle=True,
    random_state=42,
    penalty=None
)
sgd2.fit(X_norm, y)
pred_sgd2 = sgd2.predict(X_norm)
mse_sgd2 = mean_squared_error(y, pred_sgd2)
j_sgd2 = mse_sgd2 / 2

print()
print("=" * 50)
print("SGDRegressor (5000 epocas, taxa=0.001)")
print("=" * 50)
print(f"Funcao Custo J (SSE/2m): {j_sgd2:.5f}")
print(f"MSE: {mse_sgd2:.5f}")

print()
print("=" * 50)
print("RESUMO - Funcao Custo J")
print("=" * 50)
print(f"Solucao exata:         {j_lr:.5f}  (o melhor possivel)")
print(f"SGD 500 epocas:        {j_sgd:.5f}")
print(f"SGD 5000 epocas:       {j_sgd2:.5f}")
print()
print(f"Linhas usadas: {len(df)}")
```
Nossos testes foram contra a implementação do scikit-learn, tivemos de remover as duas linhas com valores faltando, pois atualmente nossa solução não suporta isso.

Aqui a Função de Custo $J$ se traduz a metade do MSE(Erro médio quadrático):
$$
J(\theta) = \frac{1}{2} \sum_{i=1}^{n} \bigl(h_\theta(x^{(i)}) - y^{(i)}\bigr)^2
$$
